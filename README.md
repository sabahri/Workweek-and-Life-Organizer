# Planner

A single-page personal planner that runs entirely in the browser. No server, no build step.

## Tabs

- **Week**: the same week repeated once per theme (for example Work, Personal, Meals), with an "Any day" column, all-day events, priority flags, done/not-done marks, sub-tasks, sub-themes, money spent with daily totals, optional day sections (Breakfast, Lunch, Dinner, Snacks, Exercise, Water), and a month calendar below.
- **Goals**: overarching goals, split into sub-goals, each with tasks and sub-tasks. Tasks can be scheduled onto the week.
- **Library**: books grouped into genres and subgenres, with reading status, interest level, search and drag-and-drop.
- **Recipes**: ingredients in sections with automatic calorie, carb and protein totals, remembered ingredients and pasted ingredient lists.
- **Pantry**: a spreadsheet-style inventory with amounts and expiry dates, sortable by name or expiry.

## Running it

Open `index.html` in a browser. Data is saved in that browser's local storage.
Use **Export backup** and **Import backup** at the top to save or move your data as a JSON file.

## Data

No personal data is stored in this repository. All entries live in the browser (or in an export file you keep yourself).
